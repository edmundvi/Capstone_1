# Capstone_1

First Capstone for DATA. Focusing on Data Storytelling, SQL, and Excel

This is my capstone project where I am acting as a data analyst for a business called EmporiUm. EmporiUm is a student bookstore chain that sells various products such as tech products and art supplies both in-store and online. The sales are segmented by sales territories within regions.
My sales manager, Miami Vue, has assigned me to gather various info and answer questions they have about our sales.
This repository includes answers to these questions using SQL scripts, and pivot charts using Excel.
